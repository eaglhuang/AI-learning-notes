- 首頁：`index.html`
- 文章列表：`articles/index.html`
- 首篇長文：`harness_engineering_article_public.html`

## 發布方式

這個 repo 使用純靜態 HTML/CSS，不需要 build step。只要 GitHub Pages 設定為從 `main` branch 的 root 發布，推送後即可更新網站。
