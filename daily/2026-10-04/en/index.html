Writing01

Simon Willison argues for default hard spending limits

Willison argues that agents make paid APIs and cloud services easier to deploy, increasing exposure to runaway usage. He advocates default spending limits that stop service at the budget ceiling, with an explicit choice required to remove them.

Try this

Set per-task and monthly agent budgets, then test that exceeding them stops usage rather than merely sending alerts.

Caveats & dates

This is a practitioner’s design argument, not evidence that every provider already supports hard caps.

Simon Willison

Products02

Prime Inference opens its model-serving platform

Prime Intellect launched Prime Inference with serverless endpoints, reserved capacity and an OpenAI-compatible interface. Its engineering account explains cross-datacenter failover, caching and scheduling for long-context agent traffic.

Try this

Evaluate cold starts, long-session latency, tool-call correctness and failure recovery together.

Caveats & dates

Performance and reliability claims are vendor-reported; API compatibility does not guarantee a drop-in workflow migration.

Prime Intellect

Writing03

BootLoops pairs verifiable calculations with domain judgment

Physicist Matthew Schwartz describes BootLoops, a harness that gives agents checkable computational tools for cross-domain research. His central lesson is that technically correct results can still lack scientific value; domain experts must guide the questions and inspect the conclusions.

Try this

Separate reproducible calculations, inspectable plots and expert acceptance into distinct checks.

Caveats & dates

This is a first-person account. Schwartz was an Anthropic visiting researcher; BootLoops is his own project.

Matthew Schwartz / Anthropic

News04

OpenAI reports reasoning-extraction activity and mitigations

OpenAI reports disrupting coordinated attempts to extract protected model reasoning and strengthening protections across users and models. The company says the activity did not directly access stored user conversations. This September disclosure concerns activity observed in July.

Try this

Review authorization and isolation around portable agent state; encryption alone does not establish safe reuse across environments.

Caveats & dates

Scope and mitigation claims come from OpenAI and were not independently verified; attempts are not successful extractions.

Products05

GPT-6.1 Sol targets lower-cost agent workflows

OpenAI introduced GPT-6.1 Sol for coding, computer use and professional tasks. Standard API prices are $2 per million input tokens, $10 per million output tokens and $0.10 per million cached input tokens; the company reports stronger performance than GPT-6 Sol.

Try this

Compare success rates, latency and cost per successful task on a fixed workload before changing model routing.

Caveats & dates

Capability gains are vendor evaluations; pricing and availability reflect the official announcement checked for this issue.

Sonnet 5.5 emphasizes efficiency at unchanged token prices

Anthropic says Sonnet 5.5 generates output over 30% faster and costs up to 30% less per task in its tests. Input and output prices remain $2 and $10 per million tokens; the savings chiefly come from lower token usage.

Try this

Compare total task-completion cost, including reasoning settings and retries.

Caveats & dates

The percentages are vendor test results, not guaranteed improvements for every workload.

Anthropic

Holo4 brings screen and tool interactions into one model

H Company released Holo4 in 27B dense and 35B-A3B MoE versions for GUI interaction, code execution, MCP and APIs. The team also publishes public-benchmark trajectories so developers can inspect the actions behind its reported scores.

The comparison uses differing harnesses, task subsets and releases, so it is not a fully controlled ranking.

Papers08

Codoku offers renewable program-reasoning tests

Codoku asks agents to fill incomplete programs under global static and dynamic constraints, with fresh puzzles generated on demand. The authors evaluated five frontier models on 300 puzzles and report that even proprietary models solved only about half of the large puzzles.

Try this

Add renewable, verifiable tasks alongside fixed coding benchmarks to reduce dependence on memorized test sets.

Caveats & dates

This preprint tests specific program puzzles, not general software-development productivity.

Cong Li, Hao Sun, Zenan Li and Zhendong Su / arXiv

Papers09

LEGO-Anything separates valid 3D artifacts from accurate scenes

LEGO-Anything has coding agents iteratively write and execute Blender programs from single images. Its benchmark uses 208 images from 104 scenes and separates artifact validity, geometry and appearance, exposing a substantial gap between usable outputs and accurate reconstruction.

Try this

Assess whether generated artifacts open, are correct and match visual requirements as separate criteria.

Caveats & dates

This is a preprint with a simulator-grounded benchmark; its natural-image results still trail specialist vision models.

Xirui Li and coauthors / arXiv
Published 2026-09-28Source ↗
Link to this pick ↗
Practice10

GitHub reports 24 Android flaws from staged AI audits

GitHub Security Lab describes staged auditing workflows and reports finding and reporting 24 Android-app vulnerabilities. The account explains why models can misjudge impact or exploitability, and why validation and researcher review remain necessary.

Try this

Try staged audits on authorized repositories, budgeting for validation, human review and token consumption.

Caveats & dates

This team report does not establish that other projects will achieve the same results.

Kevin Stubbings / GitHub Security Lab
